# Changelog

## 1.2.0

- Standardized the repository structure for public GitHub use.
- Renamed implementation files to clear, conventional names.
- Added repository checks and utility tests with no third-party dependencies.
- Hardened cross-platform filename handling for Windows-reserved names.
- Added an explicit maximum canvas-dimension safeguard for high-DPI captures.
- Bounded sticky/fixed-element scanning on very large DOMs.
- Added public security and contribution documentation.
- Retained PNG as the default image format, with JPEG and WebP options.
- Retained privacy-aware filename and scroll-restoration settings.

## 1.1.0

- Added configurable image format.
- Added website-name filename toggle.
- Added scroll-position restoration setting.
- Updated popup and settings/about UI.
